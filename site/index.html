Customer deployment · NTT DOCOMO BUSINESS

GoAT: eight regional data centers, operated as one GPU cluster.

The GPU over APN Testbed (GoAT) is NTT DOCOMO BUSINESS’s Japan-wide GPU cluster. Petasus AI Cloud is the platform it runs on.

The limit

One metropolitan site had run out of room.

  • Power and land at their limits
  • About five business days per tenant on bare metal
  • No node sharing
  • No kernel-level isolation for external customers in containers

The requirement

Distribute the GPUs, keep the performance.

  • Distributed AI data centers on the IOWN All-Photonics Network
  • Existing workloads run unmodified
  • Secure tenant isolation with fast provisioning
  • NVLink kept inside the VM

The result

One Kubernetes cluster across the country.

  • Eight data centers as one cluster since June 2026
  • 100 Gbps IOWN APN Layer-2 links
  • Heterogeneous GPU nodes and DDN EXAScaler Lustre
  • Nodes shared between tenants, each with its own guest kernel and SR-IOV paths

The platform · released in 2026

Four capabilities behind the single pool.

To our knowledge, Petasus AI Cloud is the first production-grade platform that operates GPUs in multiple wide-area-connected data centers as a single virtualized, multi-tenant pool, with GPU-to-GPU and GPU-to-storage performance preserved inside virtual machines. All four capabilities were developed in-house by SK Telecom.

01

Cross-site GPU pool

2,000 kmbetween sites, near line rate

  • KubeVirt DRA pairs each GPU with the correct NIC by PCIe and fabric topology
  • Cross-site AI storage exposes Lustre and NFS over RDMA to every site
  • GPUDirect RDMA and GPUDirect Storage stay near line rate

02

Fabric-level tenant isolation

< 1%overhead on NCCL and HPL, enforced in hardware

  • VFIO passthrough keeps NVLink intact inside the VM, which stock KubeVirt cannot do
  • InfiniBand partitioned per tenant with PKeys and SR-IOV
  • Storage reached through SR-IOV virtual functions
  • Per-tenant virtual service network with DPU-offloaded security and load balancing

03

Dynamic GPU allocation for VMs

VEP-427upstream contribution to KubeVirt

  • GPUs are allocated to virtual machines dynamically through DRA
  • SK Telecom is contributing the capability upstream to KubeVirt

04

Operational visibility and automation

40 minto reconfigure a 1,032-GPU cluster

  • GPU Insight and Traffic Flow give operators visibility across sites
  • Sixteen automation features
  • One-hour recovery of a failed node

Planned for December 2026. Unified VM and container operation with a self-service portal: multi-cluster operation, automated GPU server replacement and expansion, and driver-version-optimized VM images.

For operators

Sell the GPUs and regional sites you already own as one AI cloud.

GPUs leased as whole bare-metal servers sit idle between jobs and take days to re-provision. Where power and floor space rule out a single hyperscale site, several smaller ones cannot be sold as one product. Petasus AI Cloud addresses both.
